## Verified OK (no action needed)

* Tar extraction of text-encoder archives is strict: regular files only, no duplicates, size and count caps, containment check (`ai/nivra/inference/te_archive.py:82-116`, `internal/controller/training/te_archive.go:166-180`).
* No pickle anywhere in the model path; safetensors only, transformers loaded with `local_files_only` (`ai/nivra/modelio.py`, `text/external.py:47-48,100-127`).
* Admin session: `__Host-` cookie, `SameSite=Strict`, CSRF header plus same-origin check, bearer tokens bypass CSRF only when no cookie is used (`middleware.go:121-181`).
* Artifact downloads use server-derived content types, `nosniff`, a sandbox CSP and inline only for mp4/png (`worker_api.go:385-404`, `artifacts.go:65-74`).
* Local UI: loopback-only, `Host` check, `X-Nivra-Local` header, same-origin check; video route restricted to UUID names (`localui.go:111-136`, `app.go:852-872`).
* Fencing tokens, idempotent completion, outbox and heartbeat reconciliation survive restarts (covered by `tests/integration`).
* Windows child processes are hidden and tied to a job object, so a dead worker leaves no orphaned Python (`pyexec/proc_windows.go`).
* No secrets, passwords or tokens are tracked in git.
